##  Learn Git Branching

A hands-on lab for learning and practicing Git branching, merging, rebasing, conflict resolution, and collaborative Git workflows using Learn Git Branching.

## About

This repository contains my notes, Git commands, exercises, and lessons learned while working through the Learn Git Branching interactive tutorials.

The goal isn't just to memorize Git commands, but to understand how Git branches, commits, merges, and rebases actually work.
